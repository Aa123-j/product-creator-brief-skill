# 证据与表达边界

产品事实来自本次任务资料；此公开版本不预设产品承诺或测试结果。

| 信息类型 | 检查方式 | 写作规则 |
|---|---|---|
| 身份与功能 | 对应到准确型号和版本 | 不把其他型号的功能写入本产品 |
| 操作说明 | 对照当前使用说明 | 不以演示需要为由新增操作方式 |
| 测试数字 | 保留来源、指标、样本、周期、条件 | 不将测试均值写成每位使用者的保证 |
| 成分或部件信息 | 区分组成事实与成品结果 | 不由单一组成推导产品效果 |
| 比较 | 确认对象、标准和可比条件 | 缺少依据时换成具体展示，不作排名 |
| 个人评价 | 确认本人实际使用和原始表达 | 未确认时采用客观演示或待验证注释 |
| 当天演示 | 记录动作及观察范围 | 不将即时画面当作长期效果证明 |
| 价格与优惠 | 核对本次活动与访问入口 | 历史价格、优惠码和紧迫性不沿用 |
| 播放与转化 | 以真实后台或记录为准 | 策划假设、演示数据与实测结果分开 |

资料冲突时保留不同来源的原始口径，明确采用哪个版本及理由，不静默合并。核心承诺不支持时替换该句；不因缺少优惠或某个数字阻止其他创意完成。

对外脚本保留理解承诺所需的限定条件；完整出处可以放在内部执行注，不能把关键条件藏在无法读清的小字里。
